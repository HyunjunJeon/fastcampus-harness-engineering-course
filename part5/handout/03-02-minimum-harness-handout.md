# Session 3-2 - 최소 하네스 구성

최소 하네스는 딱 2가지 입니다.

1. 사용자 의도 파악 후 계획 세우기 
 - 사용자의 의도를 파악한다는 것은 결국 '질문' 속에 숨겨진 니즈를 파악하는 것입니다. 

2. Hook 을 통한 작업 완료를 확인하는 셋팅 
 - 사용자가 원하는 작업 의도로 만들어진 '계획'을 보고 구현하더라도 구현된 결과물은 원하는 것과 다를 수 있습니다. 따라서 이 작업의 '완료' 기준이 정확히 수행되었는지를 검증하고 통과시켜야만 합니다.
 

- `SPEC.md`, `PLAN.md`, `DONE_CRITERIA.md`를 만듭니다.
- 자동 확인 항목과 수동 확인 항목을 분리합니다.

- Codex Best practices: https://developers.openai.com/codex/learn/best-practices
