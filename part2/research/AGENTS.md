# part2/research — 강사용 1차 출처 작업 규칙

## 목적

이 폴더는 강사가 *촬영 전 한 번 읽고* 카메라 앞에서 단정적으로 인용할 수 있는 1차 출처(공식 문서·검증된 사고 사례·학회 논문) 모음이다. 루트 `AGENTS.md`의 모든 규칙이 그대로 적용되며, 이 파일은 *충돌 시 우선*하는 폴더 한정 규칙을 추가한다.

## 작업 규칙 (이 폴더 한정)

- 새 evidence 파일은 [`02-01-what-why-how-evidence.md`](./02-01-what-why-how-evidence.md)의 **8섹션 구조**를 따라간다: ⓪ 명제 / ① 매트릭스 / ② 공식 가이드 / ③ 사례 / ④ 연구 / ⑤ ★ 직결 / ⑥ 한계 / ⑦ 출처 일람.
- 모든 외부 URL은 `curl -I` 또는 WebFetch로 **200 OK 확인**. 죽은 링크는 제외 또는 대체.
- **인용 출처 화이트리스트**: 회사 공식 문서·블로그, 공식 GitHub Issue, peer-reviewed 또는 arXiv 논문, 표준 사이트(`agents.md` 등).
- **블랙리스트** (사용 절대 금지): 트위터/X, 익명 미디엄, 비공개 슬랙·디스코드 캡처, 재현 불가 회상담.
- 인용 한국어 한 줄은 **60자 이내** (강사 한 호흡).
- 원문에 없는 디테일을 추가하지 않는다. 모호한 부분은 *모호하게* 번역.
- 출처 미확인 통계는 *"확인 필요"* 로 명시하고 약화 인용으로 처리한다.

## 4종 세트 형식 (각 자료 항목 의무)

```
### [번호]. [한 줄 명제]
**출처**: [문서 제목] — [섹션]
**URL**: https://...
**확인일**: YYYY-MM-DD
**원문 (영어)**: > "..."
**한국어 (60자)**: > "..."
**세션 내 사용 위치**: 진행 순서 N번
```

## 진행 순서 매칭 매트릭스 (의무)

새 evidence 파일은 본문 대본의 **진행 순서 1~5번에 자료가 매칭되는 표**를 ① 섹션에 포함해야 한다. 부족한 순서가 있으면 ⑥ 한계 섹션에 정직하게 명시.

## ★ 직결 표시 규칙

본 세션의 *차별 명제*에 직접 대응하는 자료에만 `★`를 붙인다. 모든 자료에 ★을 붙이면 ★의 의미가 사라진다 — 통상 자료의 30~50% 이내로 제한.

## Anthropic-편중 회피

자료가 Anthropic 공식 문서에 쏠리는 경향이 있다. **OpenAI / Google / 학계 / 표준 사이트** 자료를 의도적으로 섞어 진영 중립성을 확보한다.
