# Session 1-2. 공식 문서에서 제공하지 않는 기능을 Claude Code, Codex로 찾아보기

## 목표

공식 문서에 예시가 부족하거나, 특정 오류에 대한 해결법이 없을 때, 
AI Agent 와 함께 Github Repo 를 이용해 후보를 찾고 해결책을 모색하는 방법.

## 준비물

- 공식 문서 탐색 노트
- GitHub issues 또는 changelog
- 로컬 CLI 도움말
 
## 진행 순서

1. 문서 밖 정보가 필요한 상황을 제시한다.
   - 공식 문서에는 기능 설명만 있고 실전 예제가 부족하다.
   - 에러 메시지는 있는데 공식 해결책이 없다.
   - Windows/WSL/proxy/sandbox처럼 환경 의존 이슈가 있다.

2. AI에게 "답"이 아니라 "후보"를 뽑게 한다.
   - 공식 문서에서 확인된 내용
   - GitHub issue 또는 커뮤니티 사례
   - AI의 추론
   - 검증 필요 항목

3. 후보를 상태별로 분류한다.
   - `확인됨`: 공식 문서나 로컬 실행으로 확인
   - `검증 필요`: 출처는 있으나 현재 환경에서 미확인
   - `보류`: 오래된 글, 버전 불명, 재현 실패
   - `폐기`: 현재 버전에서 동작하지 않음

4. 검증 순서를 정한다.
   - 공식 문서 재검색
   - changelog/release note 확인
   - CLI 도움말 확인
   - 샘플 프로젝트에서 최소 실행
   - 실패 원인 기록
