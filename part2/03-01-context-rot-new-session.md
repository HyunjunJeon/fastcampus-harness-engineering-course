# Session 3-1. 긴 대화가 망가지는 이유와 새 세션을 열 타이밍

## 목표

긴 대화가 무너지는 현상을 모델-도구 탓으로만 보지 않고, **컨텍스트 관리 실패로 이해**한다. 
계속 진행, 압축, 새 세션 중 무엇을 선택할지 판단한다.

## 순서

1. 긴 대화가 망가지는 증상
   - 이미 정한 규칙을 잊는다.
   - 방금 고친 파일을 다시 잘못 이해한다.
   - 이전 요구사항과 현재 요구사항을 섞는다.
   - 같은 실수를 반복한다.
   - 설명은 길어지는데 실제 진전이 줄어든다.

2. 컨텍스트 구성 요소
   - 최근 지시
   - 프로젝트 규칙
   - 읽은 파일 내용
   - 명령 실행 결과
   - 이전 대화 요약
   - 문서화되지 않은 결정

3. 새 세션 신호를 정한다.
   - 작업 목표가 바뀌었다.
   - 중요한 결정이 대화 안에만 있다.
   - AI가 오래된 전제를 반복한다.
   - 수정 범위가 커져 검증 기준을 다시 세워야 한다.
   - 사람이 최신 결정을 설명하기 어려워졌다.

4. 선택지를 비교한다.
   - 계속 진행: 작은 수정만 남았고 맥락이 선명하다.
   - 압축: 같은 작업을 이어가지만 대화가 길다.
   - 새 세션: 목표나 판단 기준이 바뀌었다.
   - 문서 분리: 반복해서 필요한 규칙이나 배경이 있다.

5. 핸드오프 노트를 만든다.
   - 목표
   - 완료된 작업
   - 남은 작업
   - 중요한 결정
   - 제약과 금지 사항
   - 검증 명령
   - 다음 세션 첫 프롬프트
