# Session 2-2. CLAUDE.md 잘 쓰기: 전역, 프로젝트, 하위 폴더 규칙 잡기

## 목표

Claude Code가 반복해서 참고할 규칙을 `CLAUDE.md`에 정리한다. 
전역, 프로젝트, 하위 폴더 규칙을 나눠 긴 프롬프트를 매번 반복하지 않게 만든다.

## 진행 순서

1. 규칙 파일이 필요한 이유를 설명한다.
   - 반복 지시를 줄인다.
   - 새 세션에서도 같은 기준을 유지한다.
   - 긴 대화가 무너져도 핵심 규칙은 문서에 남는다.

2. 규칙의 계층을 설명한다.
   - 전역 규칙: 개인 작업 방식
   - 프로젝트 규칙: 저장소의 기술 스택, 명령, 스타일
   - 하위 폴더 규칙: 특정 디렉터리의 예외와 제한

3. 좋은 `CLAUDE.md` 구조를 만든다.
   - 프로젝트 한 줄 설명
   - 주요 디렉터리 구조
   - 실행 환경
   - 자주 쓰는 명령
   - 코딩/문서 스타일
   - 테스트와 검증 기준
   - 절대 하지 말아야 할 일
   - 변경 후 보고 방식

4. 나쁜 규칙을 피한다.
   - 검증 불가능한 추상 표현
   - 오래된 명령
   - 서로 충돌하는 지시
   - 민감 정보나 토큰
   - 너무 긴 배경 설명

5. 20줄 이하의 초안을 만든다.
   - 먼저 짧게 쓴다.
   - AI에게 모호하거나 충돌하는 항목을 찾게 한다.
   - 사람이 최종 편집한다.
