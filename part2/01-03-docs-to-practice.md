# Session 1-3. 문서를 읽고 바로 실습으로 바꾸는 좋은 질문법

AI 가 읽든, 사람이 읽든 / 읽은 후 내가 필요한 정보를 얻어내는 방법.

## 목표

공식 문서 요약에서 멈추지 않고, 문서에서 말해준 기능을 토대로
실행 / 학습 가능한 실습 지시문으로 바꾼다.

## Claude Code

tool/AskUserQuestion
> 그냥 제한 없는 도구

## Codex

tool/UserRuquestInput
> Plan 모드에서만 사용 가능한 제한 있는 도구












## 진행 순서

1. 나쁜 질문과 좋은 질문을 비교한다.
   - 나쁜 질문: "MCP 설명해줘"
   - 좋은 질문: "이 프로젝트에서 MCP를 읽기 전용으로 실습하는 15분 과제를 설계해줘. 성공 기준과 실패 시 확인할 로그를 포함해줘."

2. 좋은 질문을 5개 요소로 분해한다.
   - 목표
   - 현재 상황
   - 제약
   - 산출물
   - 완료 기준

3. 공식 문서 내용을 실습 카드로 바꾼다.
   - 기능 설명을 실습 목적 한 문장으로 바꾼다.
   - 준비물을 적는다.
   - 실행 단계를 5개 이하로 줄인다.
   - 확인 방법을 명시한다.
   - 실패했을 때 물어볼 후속 질문을 만든다.

4. 바로 실행하지 말고 계획부터 받는다.
   - 파일 수정, 명령 실행, 외부 서비스 접근이 있으면 먼저 계획만 받는다.
   - 위험도가 낮으면 실행을 승인한다.
   - 완료 후 검증 증거를 요구한다.

5. 실습 후 문서화한다.
   - 이번 실습에서 재사용할 규칙은 무엇인가
   - 다음 세션에도 필요한 정보는 무엇인가
   - 대화에 남길 내용과 문서로 뺄 내용을 분리한다.
