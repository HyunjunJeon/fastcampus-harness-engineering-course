# 1 to 10 프로젝트 셋업

이 프로젝트의 목적은 '이미 있는' 코드 베이스를 리팩토링, 원하는 기능 추가를 해보는 것입니다.
여기서 하네스의 역할이 어떻게 되며, 어떤 작업을 어떻게 주는 것이 옳은지를 '고민' 해보게 됩니다.

## Git Clone

프로젝트를 활용하기 위한 빈 폴더 생성 후 클론합니다.

```bash
mkdir my-paperclip && cd my-paperclip
git clone https://github.com/paperclipai/paperclip .
```
