# API Contract

이 문서는 개발자 트랙에서 코드가 바뀔 때 함께 확인해야 하는 공개 동작 계약입니다. 비개발 트랙에서는 "코드 변경이 문서 변경을 요구하는 이유"를 설명하는 자료로 사용합니다.

## 원칙

- 공개 동작이 바뀌면 이 문서를 함께 갱신합니다.
- 예시 명령은 실제로 실행 가능한 형태로 유지합니다.
- Agent가 코드를 고쳤다면, 사람은 이 문서가 여전히 맞는지 확인합니다.

## 메모 API 계약

| 동작 | 기대 결과 | 확인 증거 |
|---|---|---|
| 메모 목록 조회 | 저장된 메모 목록을 돌려준다 | 테스트 통과, 응답 예시 |
| 새 메모 생성 | 제목과 내용을 받아 새 메모를 만든다 | 테스트 통과, 생성된 항목 확인 |
| 잘못된 입력 처리 | 필수값이 없으면 오류를 돌려준다 | 실패 케이스 테스트 |

## 문서 동기화 기준

`app/`, `tests/`, `scripts/`가 바뀌면 다음 중 하나가 필요합니다.

- 공개 동작이 바뀐 경우: 이 문서의 계약과 예시를 갱신합니다.
- 공개 동작이 바뀌지 않은 경우: `.agent/reports/docs-impact.md`의 문서 영향도 판단표에 "문서 변경 불필요"와 그 이유를 적습니다.

`bash scripts/agent_verify.sh`는 `scripts/docs_impact_check.py --require-report`를 실행해 판단표가 있는지, 문서 수정 필요 여부와 사람 확인 방법이 비어 있지 않은지 확인합니다.

## 검증 명령

비개발 트랙:

```bash
bash scripts/agent_verify.sh --docs-only
```

개발자 트랙:

```bash
bash scripts/agent_verify.sh
```
