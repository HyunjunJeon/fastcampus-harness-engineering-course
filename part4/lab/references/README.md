# lab/references — 외부 참고 자료

이 폴더는 강의 중 본보기로 함께 보는 **외부 저장소의 자료 사본**입니다. 우리가 만지는 자산이 아니라, 잘 만들어진 결과물을 그대로 보고 비교하기 위해 둡니다.

## 규칙

- 이 폴더 안의 파일은 직접 수정하지 마세요. 수정이 필요하면 `workflows/` 안에 본인 사본을 만들고 그것을 만지세요.
- 각 디렉터리에는 `NOTICE.md`가 함께 있고, 출처·커밋 해시·가져온 날짜·라이선스 위치가 적혀 있습니다. 강의 자료를 재배포·녹화할 때 이 파일을 함께 유지해야 합니다.
- 새 버전이 필요하면 각 디렉터리 안의 `NOTICE.md` 끝에 적힌 업데이트 절차를 따르세요.
